# Cow Recognition System

## Описание

Этот репозиторий содержит инструменты и модели для детекции и распознавания лиц коров на фотографиях с применением нейросетевых методов (YOLO, SimCLR) и торч-моделей. В наличии весь необходимый набор для обучения, тестирования и применения моделей, а также средства для визуализации и анализа результатов.

## Структура репозитория

- **labeled_cow_faces/** – папка с размеченными изображениями коров для обучения и тестирования.
- **train_crop.zip, test_crop.zip** – архивы с подготовленными кропами для обучения и теста.
- **best.pt** – финальный вес модели YOLO (PyTorch) для использования в инференсе.
- **main.py** – основной python-скрипт, управляющий обучением/инференсом.
- **nn.ipynb, cow-faces.ipynb** – Jupyter-ноутбуки для экспериментов, визуализации, обучения и анализа результатов.
- **README.md** – описание проекта и инструкции.
- **.gitattributes** – параметры git для работы с репозиторием.

## Быстрый старт

1. Скачайте или распакуйте исходные данные (`labeled_cow_faces/`, `train_crop.zip`, `test_crop.zip`).
2. Установите зависимости: PyTorch, torchvision, ultralytics (YOLO), Pillow, numpy, faiss, scikit-learn.
3. Для инференса используйте модель из `best.pt` с помощью main.py или команд yolo:
```
python main.py --weights best.pt --source data/test_images/
```
4. Для обучения/дообучения можно использовать jupyter-ноутбуки (`nn.ipynb`, `cow-faces.ipynb`) или вызвать main.py, указав нужные параметры.

## Описание основных компонентов

- **YOLO-модель**: обучена на размеченных фотографиях коров для задач object detection (выделение лица коровы на изображении).
- **SimCLR**: используется для обучения feature extractor’а и сравнения эмбеддингов изображений.
- **main.py**: содержит весь workflow: детекция, эмбеддинг, поиск схожих лиц, визуализация результатов.
- **nn.ipynb, cow-faces.ipynb**: подробная демонстрация экспериментов, включая загрузку данных, обучение, инференс, подбор гиперпараметров.
